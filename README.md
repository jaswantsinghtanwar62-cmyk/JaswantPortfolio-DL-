# Jaswant Singh Tanwar - Anti-Gravity Portfolio 🚀

A modern, high-performance developer portfolio featuring interactive HTML5 Canvas anti-gravity physics, 3D card tilt effects, dynamic particle repulsion, and glassmorphism UI design.

## 🌟 Features

- **Anti-Gravity Canvas Engine**: Floating particles that ascend and react with anti-gravity physics when interacting with the mouse cursor.
- **Glassmorphism UI**: Frosted glass cards styled with Tailwind CSS, subtle ambient glowing background spheres, and modern neon gradients (`#00f2fe`, `#4facfe`, `#7000ff`).
- **3D Card Tilt Effect**: Interactive cards that tilt dynamically in response to mouse movement.
- **Responsive Layout**: Fully responsive design with desktop navigation and mobile drawer menu.
- **Typography & Icons**: Modern typography paired with Google Fonts (*Space Grotesk* and *Outfit*) and FontAwesome 6 icons.

---

## 🛠️ Tech Stack

- **HTML5 & Vanilla JavaScript**: Core structure, DOM manipulation, and HTML5 Canvas API.
- **Tailwind CSS**: Utility-first styling via CDN with custom color and font extensions.
- **FontAwesome & Google Fonts**: Icons and typography.

---

## 🚀 Getting Started

Simply open `index.html` in any modern web browser:

```bash
# In Windows PowerShell:
Start-Process index.html
```

Or deploy directly to [Netlify](https://www.netlify.com/), [Vercel](https://vercel.com/), or [GitHub Pages](https://pages.github.com/).
